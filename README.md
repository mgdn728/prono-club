# PronoClub ⚽

Site de paris sportifs **gratuits** (sans argent réel) sur les vrais matchs de football.

- 1 000 pièces offertes chaque jour
- Gains versés en diamants, à échanger dans la boutique
- Comptes avec pseudo et mot de passe, classement des joueurs

Les matchs et les résultats se trouvent dans le dossier `fixtures/` (un fichier par jour) et sont mis à jour automatiquement.
